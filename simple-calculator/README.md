# Simple Calculator

A basic web-based calculator built with plain PHP and HTML. It performs addition, subtraction, multiplication, and division using a classic self-submitting form (no JavaScript, no dependencies).

## Features
- Addition, subtraction, multiplication, and division
- Input validation for non-numeric values
- Friendly error message on divide-by-zero
- Form re-populates the previously entered values after submitting

## Requirements
- PHP 8.0+

## Running locally
From the repository root:

```bash
php -S localhost:8000 -t simple-calculator
```

Then open http://localhost:8000 in your browser.
